# V2.2 标准单元测试工况库（Draft）

> 本文件为 2D CFD 标准单元测试工况**规格说明**，不含实测汇总报告。  
> 实测报告待三套对照/实验组完成后写入 `docs/report/v2.2_release实测汇总报告.md`。

## 1. 设计目标

1. 建立可复现的 2D 基准算例，用于验证六卡 KPI（kp1–kp6）
2. 覆盖实验室洁净工况与工业扰动工况的双轨评测（Lab-to-Industry-Parameter-Gap）
3. 禁止以单一洁净测试集分数替代产业落地验收

## 2. 标准单元工况（Draft 三套）

| 编号 | 名称 | 维度 | 对照组 | 实验组 | 关联 KPI |
| ---- | ---- | ---- | ------ | ------ | -------- |
| UT-2D-01 | 层流通道稳态热传导 | 2D | 纯物理求解器 baseline | Physics-AI 融合 pipeline | kp1, kp4 |
| UT-2D-02 | 后台阶突扩湍流区 | 2D | 固定网格 FVM | 自适应网格 + AI 调参 | kp2, kp3 |
| UT-2D-03 | 虚实参数漂移补偿 | 2D | 实验室参数集 | 工业扰动参数集（噪声/边界漂移） | kp5, kp6 |

## 3. 输入/输出契约

### 3.1 输入

- 几何：标准 2D 剖面（JSON/YAML 参数化，不含大网格文件）
- 边界条件：`inlet_velocity`, `wall_temperature`, `turbulence_intensity`
- 扰动工况：`noise_sigma`, `bc_drift_pct`, `sample_dropout_rate`

### 3.2 输出（仅指标，不含流场大文件）

- 残差收敛曲线摘要（max/mean continuity residual）
- 壁面热通量相对误差
- 审计切片 hash 链（见 `audit_slice_protocol_V1.0.md`）

## 4. 双轨验收门槛（Draft）

| 轨道 | 说明 | 放行条件 |
| ---- | ---- | -------- |
| Lab-Bench | 洁净参数、无扰动 | 全部 UT 用例 kp1–kp4 绿灯 |
| Industry-Shadow | 叠加工业扰动 | kp5/kp6 不触发 Critical；允许 Warning 带评审 |
