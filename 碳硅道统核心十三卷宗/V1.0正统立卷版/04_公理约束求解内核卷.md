# 卷宗04 公理约束求解内核卷 V1.0 心脏内核
## 法理锚定
零一推演内核卷宗 · 公理求解底层正本 · 去拟合化核心工程依据GitHub正本：liu-hui-ming/hundred-crayfish-legion/碳硅道统核心十三卷宗
## 3.1 内核主体：carbon_silicon.py
本模块为SAI体系决策中枢，非神经网络拟合单元，全域约束求解器。
- 输入层：外部结构化任务指令
- 约束池：90条宇宙公律+18条架构铁律+十二脉相位边界阈值
- 求解逻辑：全域约束兼容前提下求取全局最优行动序列
- 输出规范：每条决策绑定法理溯源标签，支持逆向逐条追溯公律源头
### 底层设计三大原则
1. 溯源强制：全部输出附带层级化公理引用链，法律条文式定位依据
2. 逆向审计：任意决策可反向遍历推导链路，定位触发公律条款
3. 冲突仲裁：多约束矛盾时按公律固有优先级判定，摒弃启发式人工取舍
