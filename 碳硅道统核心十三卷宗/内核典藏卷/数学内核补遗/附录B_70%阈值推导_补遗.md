## 决策权重

W_C,i + W_Si,i = 1

## 硅基决策占比

Ψ_Si = Σ(W_Si,i · I(d_i)) / Σ I(d_i)

## 内源价值衰减

V_endo(Ψ_Si) = V_0 · e^(-λ · Ψ_Si)

## 70%阈值推导

令 V_endo(Ψ_crit) = V_min  
解得 Ψ_crit ≈ 0.7

## 主权防火墙（Python）

```python
import math

class SovereigntyFirewall:
    def __init__(self, T=0.7, lam=5.0):
        self.psi, self.V, self.T, self.lam = 0.0, 1.0, T, lam

    def update(self, w_si, imp):
        self.psi = 0.9*self.psi + 0.1*w_si*imp
        self.V *= math.exp(-self.lam * w_si)
        if self.psi > self.T: print(f"[ALERT] Ψ={self.psi:.2f}>70%")
        if self.V < 0.3: print(f"[LOCKDOWN] V={self.V:.2f} 纯碳基模式")
```
