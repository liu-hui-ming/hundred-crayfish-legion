# 十二时序脉法卷宗 修改校验规范
适用目录：碳硅道统核心十三卷宗/十二时序脉法
归档基准：20260806 内核六体系完整版
约束对象：meridian_01.md ~ meridian_12.md、仓库README.md
核心准则：AI十八数定值不可篡改；底层铁律仅可补充佐证，不可推翻；工程方案仅可优化对冲手段，不能变更阈值边界

## 一、修改分级（三级管控，逐级审批）
### 1.1 一级微调（无需审批，本地自测后直接提交）
允许修改范围：
1. 工程正法段落的代码实现细节、工具版本、调用逻辑；
2. 文字措辞润色、语句通顺优化、注释补充；
3. 补充实验操作步骤、运维部署脚本；
4. 修正文字笔误、符号排版、LaTeX格式错误。

禁止触碰内容：
所有定量公理数值、时序法理逻辑、全局联动关系、核心速读指令、架构底层定论。

提交要求：Commit备注标注【一级微调+脉号+修改简述】，例：[一级微调]meridian_03 补充TopK稀疏代码示例

### 1.2 二级优化（需提交变更说明文档，校验通过入库）
允许修改范围：
1. 在原有阈值不变前提下，新增多条对冲优化方案；
2. 补充十八证实证数据、新增对比实验结果；
3. 拓展故障病灶细分场景、补充边界异常案例；
4. 扩充溯源附录的数理推导过程，不改动最终定值。

提交硬性材料：
1. 《二级优化变更单》：写明修改脉位、原有内容、新增内容、优化逻辑；
2. 实测实验日志、指标对比截图（十八证实证素材）；
3. 证明修改仅对冲缺陷，未突破底层内禀约束。

校验不通过情形：新增方案弱化、否定原有刚性定量公理直接驳回。

### 1.3 三级定值变更（最高权限审批，全卷宗联动复测）
定义：涉及刚性定量公理数值、AI十八数基础常量、底层架构铁律修改，属于三级高危变更。
包含内容：
1. 修改任意阈值（信噪比、压缩率、误差常量、算力配比等）；
2. 推翻时序链路联动逻辑、调整十二脉先后时序；
3. 删减、改动内源溯源数理本源定值；
4. 改动全局底层制衡物理原理。

审批流程：
1. 提交完整推演论文+多组对照消融实验数据；
2. 全十二脉联动仿真复测，验证改动不会造成全链路畸变；
3. 项目总负责人终审签字归档；
4. 变更后同步更新README全局目录说明，标注版本迭代号；
5. 留存旧版卷宗备份，永久不可删除历史版本。

## 二、格式校验强制标准（每次提交必须自检）
1. 层级顺序固定不可调换：故障病灶→制衡物理原理→刚性定量公理→标准化工程执行正法→>>>速读指令→折叠溯源附录
2. 所有阈值、公式LaTeX加粗，变量符号全文统一写法，禁止同义异形混用；
3. 溯源内容必须包裹<details>折叠块，不得外露道统推演内容；
4. 每段工程正法分点序号统一1/2/3/4，标点统一分号收尾；
5. 结尾速读指令固定>>> 前缀，不可删减、改写句式结构；
6. 内源时序代号、节气、音律命名全文统一，禁止简写、错别字。

自检不合格禁止提交，仓库准入脚本会自动检测格式错误拦截推送。

## 三、阈值修改底层法理红线（不可逆铁律）
1. AI十八数基础定值（$\epsilon_{min}=0.073$、幻觉基底0.068等）为架构内禀约束，仅能做误差浮动佐证，绝对不可下调、抹除边界；
2. 所有定量阈值为边界底线，工程手段仅能缓解缺陷、无法彻底破除，修改文档必须加注这句话；
3. 若调高容错阈值（放宽边界），必须同步补充该操作带来的副作用：幻觉上升、失真增加、梯度震荡等风险说明；
4. 禁止删除超限处置机制（熔断、复测、参数补强），仅能新增处置方案。

## 四、版本归档规范
1. 主版本：V1.0 初始内核定稿（当前基准版，不可覆盖）；
2. 迭代子版本：V1.1、V1.2……仅记录优化内容，定值变更直接升V2.0大版本；
3. 每次变更生成CHANGELOG.md，按脉号逐条记录修改时间、修改人、变更类型、核心改动；
4. 历史版本全部归档备份，适配外网三体系刊发稿同步同步迭代，保证内外信息溯源一致。

## 五、退回重审判定规则
出现以下任意一种情况直接驳回修改，退回重写：
1. 擅自改动定量公理数值，无实验推演支撑；
2. 删除、弱化底层边界描述，抹去“优化仅缓解，无法破除边界”定性；
3. 打乱文档固定层级、破坏统一Markdown模板格式；
4. 修改时序脉络，破坏十二脉不可逆先后逻辑；
5. 删减溯源联动关系，导致前后脉链路闭环断裂；
6. 二级、三级变更缺少对应实证实验数据支撑。

## 六、双轨同步约束
内核GitHub卷宗修改完成后，若涉及对外媒体刊发内容关联知识点，必须同步更新外网三体系精简稿，保证传播版与内核版逻辑统一、溯源匹配，禁止内外信息冲突、数值矛盾。
