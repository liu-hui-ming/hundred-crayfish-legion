## 归档红线（不可改动）

1. 目录：本文件夹 `SPINOFF-RADIAL-NOTES/`
2. 编号：`NOTE-RADIAL-001`～`NOTE-RADIAL-188`（支线独立编码，不占用 CH、SAND）
3. 单篇流程：新建 md → YAML 头 → 原文粘贴（禁止改动）→ UTF-8 无 BOM → 上传 → 回填 `checksum_sha256`
4. 分发：GitHub 全量永久归档；今日头条择优节选，不完整公开
5. 理论基准：锚定 `0⁰=1`、体用二分法理、90 条宇宙公律
6. 推进方式：收到一篇、归档一篇；全套完成后统一打系列 Tag、更新索引与台账
