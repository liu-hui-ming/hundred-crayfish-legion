开篇总纲
行业通用工程假设：
电磁干扰属于外部附加噪声；依靠屏蔽材料、差分放大、数字滤波算法，能够有效分离环境电磁
场与内源神经信号；随着电路设计优化，干扰影响持续降低，最终趋近消除。
乐观预设：干扰只是工程调试问题；只要硬件电路设计足够精良，就可以隔绝外界电磁场，完整
还原人脑原生神经活动波形，实现室内、户外全场景稳定采集。
径向公理体系证伪：
人脑神经电位属于微伏级极微弱生物电信号；日常生活工频电网、无线通信、各类电子设备持续
辐射交变电磁场，干扰幅值经常远超深层稳态神经信号。环境噪声与弥散觉知对应的低频神经活
动频谱大范围重叠，不存在数学意义上无损分离方案。
电磁干扰不是偶发脉冲扰动，是全域叠加的持续性基底噪声。实验室依靠完整电磁屏蔽舱隔绝全
域场强；离开受控空间后，基底噪声抬升，迫使系统提高信号阈值，大量表征潜意识、心境、长
期信念的微弱信号直接被判定为噪声清除。电路优化只能抑制一部分传导干扰，无法彻底抵消空
间辐射电磁场带来的基底抬升。
本条核心论断：
1. 幅值悬殊公理：神经源信号幅值（0.5μV～50μV）；民用环境电磁干扰幅值经常达到数十至数百
微伏，深层微弱觉知信号极易被噪声基底吞噬；
2. 频谱重叠困境：50Hz/60Hz工频谐波、射频低频分量，与低频漂移型稳态神经信号频带重合；线
性滤波无法选择性保留生物信号、剔除同频段电磁场干扰；
3. 双层约束链条：外部电磁场抬升噪声基底 → 设备被迫收紧滤波阈值 → 稳态微弱觉知分量被截
断丢弃；
4. 场景分化边界：封闭屏蔽环境基底噪声极低，可观测完整信号谱系；居家、办公、户外持续存
在复合电磁场，天然只适合捕捉高幅值瞬时心念脉冲；
5. 衍生推论：任何无外置重型屏蔽的便携径向终端，物理层面上限只能稳定解析表层清晰心念；
想要持续采集深层弥散觉知活动，长期依赖屏蔽空间，不具备全天候民用普及基础；商业宣传中
“全场景深度脑信号采集”违背底层电磁物理约束。
微电藏颅底，尘寰电磁场；底噪层层起，幽澜不可扬。
一、信号与电磁干扰层级对照模型
内源神经信号分层
1. 瞬态脉冲信号（清晰心念、突发情绪）：10～50μV，特征陡峭、变化速率高；抗干扰能力较
强，噪声环境下尚有机会识别；
2. 稳态弥散背景信号（心境、潜意识缓慢演化、长期信念活动）：0.5～8μV，低频缓慢漂移；幅
值与环境电磁基底噪声处于同一区间，最容易彻底淹没。
现实环境电磁干扰来源（开放场景永久存在）
1. 工频干扰：照明、插座、充电器、家电产生50Hz基波与大量谐波，全域持续性基底噪声；
2. 射频辐射：路由器、手机、蓝牙设备、显示屏交变电场；
3. 静电与位移电场：人体移动、衣物摩擦带来瞬时电场扰动；
4. 地线电位浮动：楼宇供电地线压差，引入共模干扰。
二元概念严格界定
【可耐受扰动】短时、高频、大幅度脉冲噪声；波形特征和神经瞬态脉冲区分度较高，算法有概
率识别、剔除；
【毁灭性基底噪声】持续存在、低频、宽幅电磁场基底抬升；直接压缩微弱生物信号动态区间，
造成永久性观测盲区。
二、五条核心推演定理
定理1：差分放大电路仅抑制共模干扰，无法解决空间电场基底抬升
大众技术误区：采用差分电极方案即可隔绝电磁场。
物理事实：差分架构能够抵消两根电极同步拾取的共模噪声；但头部空间电场梯度、电极接触阻
抗不均衡会转化为差模干扰，直接混入有效数据流。环境电磁场越强，差模转化分量越高，无法
彻底根除。
定理2：屏蔽方案存在重量、功耗、成本三重民用天花板
完整电磁屏蔽需要导电密闭腔体；轻薄织物屏蔽效能有限，对低频工频电磁场抑制效果极差。
想要达到实验室级屏蔽效能，设备体积、重量、造价将脱离消费产品区间。轻量化民用径向设备
只能做到部分射频抑制，无法压制工频低频干扰。
定理3：电磁基底抬升放大原型误读概率（联动078原型预设）
噪声混入数据流，扭曲原始波形。当微弱真实信号被淹没，剩余畸变特征送入解码模型；
模型不会输出未知状态，而是就近匹配最接近的情绪/心念原型，持续生成虚假识别结果。电磁污
染加剧“拟合幻觉”。
定理4：干扰效应具备非叠加随机性，无法通过平均采样完全消除
多次信号平均可以削弱随机白噪声；但环境电磁场存在周期性、定向性，属于有色噪声。简单时
域平均难以彻底剥离；长时间连续采样只会持续累积畸变特征，不能还原底层弥散觉知信号。
定理5：侵入式设备依旧无法完全规避电磁场影响
颅内电极规避头皮表皮电场扰动，但脑组织依旧处在外部交变电磁场之中。侵入方案仅改善接触
信噪比，不能隔绝空间传播的全域电磁场；深层低频神经活动依然面临同频段噪声竞争。
三、四类主流产业认知谬误辨析
谬误1：不断优化芯片前端，最终彻底消除电磁干扰
祛魅。芯片电路只能优化信号放大与抗干扰能力，不能改变外部客观电磁场强度，也无法解决同
频段信号不可分割的物理局限。硬件迭代可以小幅改善信噪比，但不存在“彻底消除干扰”的终
点。
谬误2：使用有源降噪算法，能够滤除所有工频电磁场
祛魅。有源工频抵消依赖稳定不变的噪声频率与幅值。现实场景电器随时启停、场强持续波动；
自适应抵消算法极易产生过度修正，同步扭曲同频段生物低频漂移信号。
谬误3：远离电器、保持环境简洁，就能接近实验室信号质量
祛魅。电网工频电磁场遍布所有建筑内部，无法彻底脱离。仅能小幅降低干扰强度，不能抵达屏
蔽舱的极低噪声基底；微弱稳态觉知信号依旧处在观测盲区。
谬误4：高频无线频段干扰无关紧要，只需要处理50Hz工频
祛魅。射频电磁场经过人体、电极非线性调制后，会向下产生互调低频分量，落入神经信号有效
频带。单纯过滤工频，忽略射频辐射，依旧存在持续性隐性噪声源。
四、产业观测与研发叙事分层约束准则
1. 场景性能分层判定
无重型电磁屏蔽的便携径向设备：仅可信任高幅值瞬态心念、基础情绪识别结果；一切宣称解析
潜意识、深层心境的功能，可信度极低。
2. 测试标准硬性要求
所有脑机产品公开测试数据，必须标注测试环境是否具备电磁屏蔽；禁止直接使用屏蔽舱采集的
优质数据，作为开放场景性能宣传依据。
3. 产品设计取舍参考
民用产品应当主动放弃低频稳态信号采集目标，聚焦表层瞬态交互；若强行宣称深层探测能力，
必然依靠算法原型拟合制造识别幻觉。
4. 实验复现规范
跨场景对比实验，必须记录环境电磁场强度；噪声基底不同环境下的实验结论，禁止直接横向等
同。
