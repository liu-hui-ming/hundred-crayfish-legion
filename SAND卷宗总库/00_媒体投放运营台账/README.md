# 00 · 媒体投放运营台账

## 定位

本目录存放**媒体报价、渠道排期、投放执行**等商业运营资料，与 🔴 内核法理只读区物理隔离，**不参与法理推演与学术引用**。

## 存放规范

| 类型 | 说明 |
| --- | --- |
| 媒体渠道报价表 | 各渠道单价、套餐、折扣条款 |
| 投放排期 | 50家合作媒体档期与执行状态 |
| 商业台账 | 合同编号、对账记录（脱敏后） |

## 红线

- 禁止放入 `碳硅道统核心十三卷宗/` 及任何公理法典真值目录
- 禁止与 SAND 媒体通稿母稿混放
