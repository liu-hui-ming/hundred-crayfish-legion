二、正本清源：两层信息客体刚性二分
第一层：神经信息（0态觉知原生信息）
核心特征：
1. 源头来自碳基活体觉知时序，直接映射心念、情绪、内在意向；
2. 高度人身依附，与主体人格完整性、思想自由深度绑定；
3. 泄露风险不可逆，无法像密码一样重置；
4. 可被采集记录，但不可彻底与主体剥离、不可无限自由交易；
本质：人类精神活动的数字化载体，最高等级敏感人格信息。
第二层：自然人数字镜像/数字分身（1态衍生仿真信息系统）
核心特征：
1. 依托原生人格素材经算法拟合生成，属于外在行为复刻，不承载真实觉知；
2. 形态可复制、可修改、可重建；
3. 存在两层权益分离：算法程序、硬件载体归属服务商；镜像人格表达权益归属自然人；
4. 镜像一切言行的外部责任，原则上溯源至授权本体；
本质：以碳基人格为模板构建的符号仿真产物，次生衍生信息。
核心分界公式
神经信息 = 觉知原生投射 → 本体永久完整权属，仅可授予限定许可
数字镜像 = 原生素材+算法拟合衍生品 → 素材权属归自然人，算力服务归运营方
载体投入只能换取使用权，不能夺取精神信息本源控制权；衍生品依附本源，不可反向脱离本
源独立确权。
类比：
神经信息等同于一个人内心思想的文字记录；数字镜像等同于依据此人言行拍摄的长篇虚拟影
像。
影视制作公司投入设备、后期算力，可以获得影片放映许可；但不能买断人物形象、思想表达
的人格权利，不能私自篡改影像内容、不能无限跨界商用；原型人物随时有权要求影片下架、
彻底销毁原始素材。影像无论剪辑迭代多少次，根源依旧依附原型本人。
