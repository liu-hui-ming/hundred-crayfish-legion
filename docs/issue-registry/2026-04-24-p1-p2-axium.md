### XIAN_LANDING_NOTES_2026_06_08

基于硅碳同盟四层架构图，XIAN 项目落地拆解锚定 P1 原子地基边界：

| 架构层 | XIAN P1 原子地基 / 当前在建内容 | P2 及后续阶段预留模块 |
|--------|--------------------------------|--------------------------|
| 控制面 | GitHub Issue 一日一发、台账归档、固定 Checklist、人工复核 / 审批 | 可视化工作流编辑器、正式项目 / 目标管理、更完整审批中心 |
| 智能协作层 | 固定 XIAN 角色口径、日报模板、smoke / 安全 / 备份 Checklist、SOP 驱动的问题分类 | Agent / 模型 / 工具配置、知识库、上下文记忆、质量 / 成本统计 |
| 百龙虾军团执行层 | 本地脚本、一键发布 PowerShell、WSL smoke 路径、bounded-swarm / probe 式验证 | 分布式调度、多节点 Worker、重试 / 补偿服务、资源配额编排 |
| 数据与基础设施层 | `docs/issue-exports/`、日报台账、环境台账、缺陷清单、社群安全债项台账、备份校验记录 | PostgreSQL / Redis 持久化、对象存储、完整可观测系统、密钥 / 配置中心 |

当前在建重点：XIAN 先作为可追踪的 P1 工作流落地，保证能发布、能归档、能验证、能回滚；所有一日一发输出必须绑定 Issue 链接、标题/正文稿、脚本路径、标签与台账记录。

P1 边界备注：P1 暂不承诺完整自治工作流平台能力，重点交付可靠记录、可复用脚本、人工审批、smoke 检查、安全 / 备份 / 费用 / 架构日志归档与台账一致性。

P2 及后续预留：可视化工作流编辑、Agent / 工具 / 模型配置、知识记忆、外部系统集成、成本质量分析、分布式执行、租户隔离、高可用与插件 / 模板生态。
