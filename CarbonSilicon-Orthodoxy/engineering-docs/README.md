> **仓库**：`hundred-crayfish-legion`  
> **根路径**：`CarbonSilicon-Orthodoxy/engineering-docs/`

## 目录分区（物理隔离）

| 子目录 | 存放分支 | 定位 |
|--------|----------|------|
| `media-release/` | `main` | 50 家综合媒体投放通俗科普稿，全团队只读，可摘抄分发 |
| `sealed-academic/` | `private-core` | 内核涉密学术封存稿，仅创始人与刘慧明可查阅 |
| `official-archive/` | `private-core` | 核心卷宗完整底稿（双零临界标杆188条满分重构版等），仅内部可查阅 |

## 对外发布规则

- **对外媒体、短视频、评论投放**：仅可使用 `main` · `media-release/` 精简版本。
- **学术封板稿、完整数理推演、九翼涉密参数、official-archive 完整底稿**：仅存 `private-core`，**严禁**公域外流。
- **仓库内禁止**：可直接公域传播的引流话术、彩蛋宣传文案。

## 分支隔离

`private-core` 内核私有分支**严禁合并**至 `main` 或任何公网 public 分支。
