## 目录分区（物理隔离）

| 子目录 | 存放分支 | 定位 |
|--------|----------|------|
| `media-release/` | `main`（本分支） | 50 家综合媒体投放通俗科普稿，全团队只读，可摘抄分发 |
| `sealed-academic/` | `private-core` | 内核涉密学术封存稿，**不在 main 分支** |
| `official-archive/` | `private-core` | 双零临界标杆等核心卷宗完整底稿，**不在 main 分支** |

## 对外发布规则

- **对外媒体、短视频、评论投放**：仅可使用本目录 `media-release/` 版本。
- **学术封板稿、完整数理论证、九翼涉密参数**：仅存 `private-core` 分支，**严禁**公域外流或从 main 分支访问。

## 分支隔离

`private-core` 内核私有分支**严禁合并**至 `main` 或任何公网 public 分支。
