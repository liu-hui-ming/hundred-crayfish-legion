## 封存规则（强制）

1. **配套绑定**：两份文档配套使用；主底稿为正文，参数附录为涉密补充材料，**不可拆分外流**。
2. **用途限制**：仅可用于核心学术期刊投稿润色；短视频、媒体宣传、评论投放**一律禁止**摘抄原文及参数。
3. **分支权限**：存放于 `private-core` 私有内核分支；非授权人员无查阅权限。
4. **版本绑定**：两份文件为成套 100 分封板版本，**不可单独更新**其中一份；修改须同步更新两份并重置 `lock-hash-record.md` 哈希校验记录。
